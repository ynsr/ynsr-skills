## Per-sample flow detail

- **tagprobe (bash/agent)**: `scaffold.sh` → `./check.sh` (bashly generate + shellcheck +
  bats 13/13 + verify-cli 11/11) → `show probe.json` (exit 0, JSON rows on stdout) →
  `delete probe.json --dry-run` (plan on stdout) → `delete probe.json --yes` (file removed) →
  verify-cli `show`/`delete` probes. (Post-fix run had no install/uninstall — those were
  exercised on the pre-fix sample and in the other three tiers.)
- **fetchone (python-single-file/human)**: `scaffold.sh` → `./check.sh` (throwaway stub API +
  `FETCHONE_TOKEN`/`FETCHONE_URL` env-only secrets + verify-cli 10/1-skip) → `items widgets`
  against stub (exit 0) → `delete widgets 42 --dry-run` → `delete widgets 42 --yes` (HTTP 204)
  → verify-cli → install (symlink) → `doctor` (exit 1, `status: missing` — token env unset
  outside check.sh env, correct behavior) → uninstall (link gone).
- **apifetch (python-project/agent)**: `scaffold.sh --profiles` → `make check`
  (uv sync + ruff + pytest + verify-cli 11/11) → `list widgets --limit 2` (exit 0, CSV agent
  default) → `profile create demo --url … --default` → `profile remove demo --dry-run`
  (plan printed, file kept) → `profile remove demo --yes` (store file removed) →
  install (`uv tool install --editable .`) → `doctor` (`status: ok`) → uninstall →
  verify-cli `list widgets`/`profile remove demo` probes.
- **watchrun (go/human)**: `scaffold.sh` → `./check.sh` (golangci-lint + go test + verify-cli
  11/11) → `go build` → `list` (pretty table, human default) → `delete rmme.txt --dry-run`
  (plan) → `delete rmme.txt --yes` (slog INFO to stderr, file removed) → install (static
  binary to ~/.local/bin) → `--version` → uninstall (binary gone) → verify-cli
  `list`/`delete` probes.
