### 4.1 Universal contract (SKILL.md, ≤12 bullets; `verify-cli` enforces the machine-checkable subset)

1. Stdout carries data only; logs/progress/prompts → stderr.
2. `--output/-o` accepts `table|json|csv|tsv`; `--json` alias. Precedence: `--output` > `--json` > audience default. Human default `table`; agent default `csv` (flat) / `json` (nested). Machine timestamps ISO-8601 UTC.
3. Exit codes `0` success, `1` error, `2` usage, `3` network, `4` partial — 3/4 only when needed; documented in `--help`.
4. Never block on input. `--no-input`, or non-TTY stdin/stdout or `CI` set → fail with an actionable message. Prompt only with a TTY.
5. Honor `NO_COLOR` and `TERM=dumb`; provide `--no-color`.
6. `--version`, `-v`/`-q` on every tool. Destructive actions: `--dry-run` prints the real records/requests; execution needs `--yes`/`--force`.
7. Errors: humans get a styled one-liner + hint; agents (non-TTY or `--output json`) get `{"error":{"code","message","hint"}}` on stderr with matching exit code.
8. Agent tools: `--fields` and `--limit`/pagination on list commands; `schema`/`commands` introspection subcommand (Click tree + pydantic JSON Schema).
9. Human tools: pager for long output; did-you-mean hints where the framework lacks them.
10. Secrets from env vars or 0600 files, never flags. Precedence flag > env > profile > default.
11. Install/uninstall idempotent; uninstall reverses everything.
12. Completion generated by the framework, installed by file drop into the shell's autoload dir; dynamic callbacks read local state only, import lazily, return `[]` on failure. ble.sh-safe (project memory invariant).

### 4.2 verify-cli contract

Single bash script. Usage: `verify-cli <path-or-command> [probe-read-subcmd] [probe-destructive-subcmd]`. Checks:

| # | Check | Method |
|---|---|---|
| 1 | `--help` exit 0 and mentions exit codes; `--version` exit 0 | run + grep |
| 2 | Stdout purity: data only with `2>/dev/null` | probe run, empty-or-data |
| 3 | `--output json` parses (`jq -e .`); `-o csv` has non-empty header row | probe run |
| 4 | Non-TTY never blocks | `timeout 5 <cmd> </dev/null` |
| 5 | No ANSI escapes under `NO_COLOR=1 TERM=dumb` | grep escape bytes |
| 6 | Error envelope + exit codes | bad subcommand → 2 + `{"error":…}` on stderr (json mode / non-TTY) |
| 7 | `--dry-run` without `--yes` changes nothing, exits 0, prints plan | probe destructive |
| 8 | Completion generation succeeds, non-empty | framework's generator |

Exit 0 all pass; failures listed, exit 1. Scaffolded `check` target wires lint + tests + `./scripts/verify-cli "$@"`.

## 5. Spikes (time-boxed; each yields a DECISIONS.md row: choice, why, rejected alternatives, evidence)

- **A — Python picker**: questionary vs raw prompt_toolkit vs iterfzf (InquirerPy only if actively maintained). Must render on stderr, return `None` on non-TTY without blocking, restore terminal on Ctrl-C. If none routes to stderr cleanly: keep ≤20-line wrapper.
- **B — Python completion**: framework-generated scripts installed by file drop (`~/.local/share/bash-completion/completions/<tool>`, `~/.config/fish/completions/<tool>.fish`, zsh fpath line documented). Reproduce the Typer ≥0.27 `add_completion=False` failure on latest Typer; test under ble.sh (installed here). Fixed upstream → delete `ensure_completion_classes()`; else shortest workaround + issue link. Dynamic callbacks import lazily; measure Tab latency (`python -X importtime`).
- **C — Install without stale copies**: `uv tool install --editable .` for projects; symlink into `~/.local/bin` for single-file. Works → delete receipt, stale guard, dev-warning. `doctor` survives as health check (deps, config, connectivity) and still prints `status: ok|missing` (`stale` never emitted) because cli-hub consumes the contract. Propose hub-side metadata derivation (separate note).
- **D — Bash generator**: bashly (YAML→standalone, completions via `completely`) vs argc (comment tags, multi-shell). Judge: Ubuntu install effort, standalone output, help/completion quality, agent-writability. Reason in ≤5 lines.
- **E — Go stack**: cobra + fang (self-declared experimental — check stability, NO_COLOR, non-TTY), huh for pickers/forms, table lib: lipgloss/table vs go-pretty (one definition → table/CSV/JSON with least code). `retryablehttp` for retries; slog to stderr.
- **F — Scaffolder**: copier (`uvx copier`) vs plain `scaffold.sh`. Judge: maintenance load, offline operation, determinism, single command producing a working tested skeleton with parameters (tier, audience, name, features).

## 9. Migration notes for existing generated CLIs

- Old receipt tools: `doctor`'s stale-check is gone in NEW tools; existing installs keep working as-is — no forced migration. Optional: delete `~/.local/share/<tool>/install-receipt.json` when re-scaffolded.

- cli-hub entries: register interface unchanged → entries stay valid; `reinstall`/`uninstall` hooks re-run the (rewritten) install.sh, which keeps the same register call.
